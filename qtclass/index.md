# 量潮课堂

量潮课堂是量潮科技面向学习者开放的一条成长通道。在这里，学习沿着一条逐渐开放的轨迹展开：从有标准答案的课堂任务起步，到承接真实商业任务，再到自主选题、独立交付，直至承担公司运营中的真实职责。每一步都比上一步更开放，也更接近真实工作。

## 从课堂任务走向真实工作

学习从可控的环境开始。课堂任务有明确的题目与验收方式，适合建立基本的手感和工程习惯。

随后，学习者可以认领量潮真实的商业任务——小说发行、小游戏发布、工具实操、数据整理。这些任务来自公司的实际业务，交付物外部可见，验收以真实结果为准。

再往前，学习者可以申请立项一个自己的方向，独立交付一个小课题；表现突出者进入实训基地，参与真实项目与业务运营，甚至被选拔为基地代表，拥有提案权与投票权，参与课题初审与规则制定。

这条路径没有固定的学期和门槛。学习者按自己的节奏推进，越往前，自由度与责任越大。
